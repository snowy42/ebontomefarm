## Delivered behaviour

- Reset build (tracker footer, Settings or /etf reset) confirms, clears this
  build's manual marks and skips, rescans actual ownership/bags, and pauses
  for review. Build imports, real unlocks, personal pins, filters and manual
  marks unrelated to its targets are preserved. Click Start route afterwards.
- Replan (/etf reroute also accepted) rescans and starts at the nearest source,
  finishes its native map zone, and picks each next farm from actual player
  position when the current farm completes. Count/priority weighting cannot
  send a nearby player to a distant raid. Current continent is preferred;
  no shortest cross-continent travel distance is claimed. Missing position
  waits; an open map is not forcibly switched. Manual marks are kept.
- One-second bag polling plus bag/loot events enqueue a five-second TOME FOUND
  banner, optional sound and chat line for new tome families, even with the
  tracker hidden or paused. Login baseline and per-session dedup avoid spam.
  /etf testalert is an explicitly labelled, non-mutating preview.
